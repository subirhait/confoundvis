# Replication materials for the confoundvis 0.3.1 article

* `confoundvis_replication.R` reproduces every code chunk, figure, and number
  in the article and runs the numerical checks. Run it from this folder:
  `Rscript confoundvis_replication.R` (or "Source with Echo" in RStudio).
* `confoundvis_timing.R` reproduces the computing-time table.
* `confoundvis_output/` holds the outputs of both scripts: the printed
  output, Figures 1-5, the numbers quoted in the text, the grid-step study,
  the timing table, the check results, and the session information.
